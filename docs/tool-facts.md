# Claude Code facts for the workshop

Checked on 2026-10-18. Local authoring CLI: `2.1.302 (Claude Code)` from `claude --version`. The prepared participant VMs may have a different version; check `claude --help` and `/help` there. These references establish product behavior, not participant entitlements or successful execution of paid requests.

- Interactive CLI starts with `claude`; `-p` / `--print` runs noninteractively. `--resume` and `--continue` can continue saved context in print mode. `--allowedTools`, `--disallowedTools`, `--max-turns`, `--max-budget-usd` and `--output-format json` are documented flags. [CLI reference](https://code.claude.com/docs/en/cli-reference).
- `/resume`, `/compact`, `/context`, `/model`, `/permissions`, `/mcp`, `/hooks`, `/plan` and `/help` serve different purposes. Session continuation does not restore the repository. Checkpoints do not undo arbitrary shell or external effects. [Interactive commands](https://code.claude.com/docs/en/interactive-mode), [checkpointing](https://code.claude.com/docs/en/checkpointing).
- `CLAUDE.md` is native memory. This repository imports `AGENTS.md` explicitly through `@AGENTS.md`. `.claude/rules/*.md` may use `paths` frontmatter. Keep the instruction file concise; 200 lines is guidance rather than a permission control. [Memory](https://code.claude.com/docs/en/memory).
- Settings use `permissions.allow`, `ask`, `deny`; `denyTools` is not the corresponding settings key. Sandbox filesystem/network restrictions and tool permission decisions are separate layers. [Permissions](https://code.claude.com/docs/en/permissions), [sandboxing](https://code.claude.com/docs/en/sandboxing).
- Subagent Markdown definitions use frontmatter including `name`, `description`, `tools`, `model`, `permissionMode` and optional `memory`. `Agent` replaced the old `Task` tool name in 2.1.63; compatibility aliases remain. In recent versions `/agents` points to editing definitions rather than the old wizard. [Subagents](https://code.claude.com/docs/en/sub-agents).
- Agent Teams is experimental, disabled by default and enabled through `CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1`. Separate sessions in worktrees do not by themselves constitute this feature. [Agent teams](https://code.claude.com/docs/en/agent-teams).
- Claude Desktop and Cowork support Linux in beta. Cowork requires KVM/QEMU, virtualization access, disk and memory; nested virtualization on the supplied VM is unverified. The Hyper-V point in the purchased program applies to Windows. Linux Desktop currently lacks computer use and dictation. CLI is the workshop's programming route. [Desktop availability and requirements](https://support.claude.com/en/articles/10065433-install-claude-desktop).
- Web sessions run in a separate cloud environment with repository access, network configuration and setup scripts. This is distinct from Remote Control of an existing session. [Claude Code on the web](https://code.claude.com/docs/en/claude-code-on-the-web).
- Project MCP servers use `.mcp.json`; the Linux Playwright example uses `npx` directly. Skills and simple custom commands remain separate authoring options. [MCP](https://code.claude.com/docs/en/mcp), [skills](https://code.claude.com/docs/en/skills).
- Hook `if` conditions and `type: agent` are supported in current docs. The unrelated Maven hook is retained as an inactive example, not enabled for AI Chat. [Hooks](https://code.claude.com/docs/en/hooks).
- Opus, Sonnet and Haiku aliases resolve according to account/provider configuration; they are not fixed model IDs or a universal quality ranking. Z.AI documents GLM-5.3 integration; Ollama documents an Anthropic-compatible route to local or cloud models. Gemma 4 is an available open-weight model family; no inference performance on an 8 GB VM is claimed. [Model configuration](https://code.claude.com/docs/en/model-config), [GLM](https://docs.z.ai/devpack/tool/claude), [Ollama](https://docs.ollama.com/integrations/claude-code), [Gemma 4](https://deepmind.google/models/gemma/gemma-4/).
- Current AI SDK UI docs use `useChat` from `@ai-sdk/react`, message `parts`, a transport and matching UI message streaming on the server. Pin and verify the version during the course ADR before coding. [AI SDK chatbot](https://ai-sdk.dev/docs/ai-sdk-ui/chatbot), [useChat](https://ai-sdk.dev/docs/reference/ai-sdk-ui/use-chat). Verified Context7 IDs: `/websites/ai-sdk_dev`, `/websites/code_claude`.
- The inactive example in `course-materials/cicd-headless/claude-code-ai-chat.yml.example` uses the official `anthropics/claude-code-action@v1`. Authentication can use an API key or a supported OAuth token. API spend, subscription usage and GitHub runner costs are distinct. `/usage` reports local estimates; provider billing is authoritative. [Action setup](https://github.com/anthropics/claude-code-action/blob/main/docs/setup.md), [action usage](https://github.com/anthropics/claude-code-action/blob/main/docs/usage.md), [cost management](https://code.claude.com/docs/en/costs).

Archived examples under `course-materials/` retain their own dates and may need re-verification. The workshop does not activate every example in that library. Public `write-prd` and `write-adr` skills are sourced from [EdukeyTeam/agent-toolbox](https://github.com/EdukeyTeam/agent-toolbox).
