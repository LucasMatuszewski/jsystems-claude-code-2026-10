## RULE (from FIX-09)
Never run two Playwright processes (test runner, capture, or a second project run) at the same time in `app/`: they share `test-results/`/`playwright-report/` and corrupt each other (ENOENT on traces, wiped artifacts). Run every Playwright command strictly sequentially and copy artifacts to `app/qa-artifacts/<task>/` after each run. Server logs (`ai_call` JSON lines with outcome, totalMs, msToFirstChunk, finishReason, reasoningTokens) are now piped into the Playwright output — include them in your diagnosis of any failure.
