# P21 - Repomix: pomiar i wybór kontekstu

Użyj Repomix w sprawdzonej wersji. Nie instaluj innej wersji ani nie zmieniaj aplikacji bez uzgodnienia. W klonie jFTP przygotuj pełną paczkę plików Java i POM, skompresowaną paczkę z dokładnie tym samym zestawem plików oraz pełną paczkę wybranego małego obszaru.

Zapisz wersję narzędzia, commit, polecenia, zestaw plików, wykluczenia i liczbę tokenów. Dla kompresji porównuj ten sam zakres. Dla wyboru obszaru pokaż osobno, które pliki usunęliśmy z kontekstu. Porównaj jeden skompresowany fragment metody z oryginałem: wskaż brakujące warunki, operacje i inne elementy potrzebne do ustalenia zachowania.

Nie czytaj automatycznie całej paczki do kontekstu sesji. Przeszukuj ją i pobieraj fragmenty związane z pytaniem. Zanim oceniasz zachowanie lub edytujesz metodę, otwórz oryginalny kod i potrzebne wywołania. Oddaj pomiary oraz krótkie uzasadnienie, który zakres pomoże w naszym zadaniu. Paczek nie dodawaj do Git ani do plików instrukcji ładowanych przy starcie agenta.
