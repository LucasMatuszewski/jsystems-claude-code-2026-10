# P20 - Inwentaryzacja bez naprawiania aplikacji

Pracuję w oryginalnym klonie jFTP. Zapisz commit, stan Git i dostępne narzędzia. Nie zmieniaj kodu ani konfiguracji.

Zacznij od listy plików i wyszukiwania. Ustal pakiety, katalogi źródeł i zasobów, entry pointy, konfigurację budowania oraz zależności. Wyszukaj importowane typy, których definicji nie ma w klonie. Nie utożsamiaj podobnego prefiksu pakietu ze wspólnym pochodzeniem kodu. Zaznacz granicę aplikacja / kod wielokrotnego użytku / zależność zewnętrzna.

Przeczytaj reprezentatywne pliki zamiast wczytywać całe repo. Jeśli narzędzie budowania jest dostępne, odtwórz pierwszy błąd; nie naprawiaj go teraz. Oddaj `docs/discovery/inventory.md`: mapa, przeczytane i pominięte obszary, konkretne ścieżki i symbole, polecenie z wynikiem oraz niewiadome. Odróżnij obserwację w kodzie, hipotezę i wynik uruchomienia.
