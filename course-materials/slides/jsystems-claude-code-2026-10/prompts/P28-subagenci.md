Na podstawie aktualnego `docs/PRD.md`, właściwych ADR-ów i instrukcji repozytorium pomóż mi zdefiniować zespół Claude Code do budowy AI Chat. Najpierw przeczytaj strukturę aplikacji, sprawdź kontrakt streamingu i polecenia testów. Nie uruchamiaj agentów ani implementacji w tym zadaniu.

Przygotuj własne definicje `.claude/agents/be-developer.md`, `.claude/agents/fe-developer.md` i `.claude/agents/qa-engineer.md`. Porównaj je z nieaktywnymi przykładami `course-materials/agent-configs/claude/agents/`, otwierając tylko te trzy wskazane pliki. Każda definicja ma poprawny frontmatter `name`, `description`, `tools`, `model` oraz świadomie dobrany `permissionMode`. Opcjonalne `memory: project` uzasadnij i wskaż, jak zapobiec zapisaniu sekretów lub danych rozmów. Zweryfikuj składnię w bieżących dokumentach Claude Code i wersji CLI; nie odtwarzaj kreatora `/agents` ze starego kursu.

Backend odpowiada za walidację wiadomości, integrację dostawcy i endpoint zgodny z protokołem streamingu AI SDK UI. Frontend odpowiada za React `useChat`, wyświetlanie `parts`, stany wysyłania, błędu i kontynuacji rozmowy. QA sprawdza kryteria PRD, testy, działanie rzeczywistej aplikacji i ryzyka bezpieczeństwa. Każda rola ma zacząć od wymagań, zapisać dowód nieprzechodzącego testu, a następnie najkrótszą poprawną implementację. Nie nadaj automatycznie uprawnień do push, deploy, sekretów ani dalszej delegacji.

Dla każdej roli zapisz: kiedy ją wywołać, wejścia i zależności, dozwolone pliki, obszary poza zadaniem, narzędzia, oczekiwany raport i moment zatrzymania. Wspólny kontrakt API, `package.json` i lockfile muszą mieć jednego wskazanego właściciela. BE i FE mogą pracować równolegle dopiero po ustaleniu kontraktu; QA może wcześniej przygotować scenariusze, lecz test całej aplikacji wymaga integracji.

Zaproponuj po jednym małym pierwszym zadaniu, z jasnym kryterium i testem. Pokaż prompt delegowania przez `Agent` (starsza nazwa: `Task`) i sposób weryfikacji raportu. Główny agent ma odczytać diff i uruchomić właściwe sprawdzenie, a człowiek zatwierdza zachowanie. Rozróżnij zwykłych subagentów od eksperymentalnych Agent Teams; nie włączaj Teams w tle. Jeśli brakuje kontraktu lub ścieżek, zapytaj zamiast je wymyślać. Zakończ po przeglądzie definicji i briefów; delegowanie zlecę osobno.
