Moduł 1.1 | Weryfikacja środowiska

Fork, clone i branch - start pracy z repo

Kroki startowe (RAZEM)

  1. Fork repo kursowego na swoje konto GitHub
  2. Clone swojego forka na VM
  3. Dodaj upstream (repo trenera) - stąd pobierzesz aktualizacje
  4. Utwórz branch roboczy - aplikację budujemy zawsze na branchu, main zostaje na materiały
  5. Uruchom codex albo claude w katalogu projektu
Aktualizacje od trenera (w trakcie i po kursie - nowe przykłady, historia czatu, podsumowania): git checkout main && git pull upstream main

Kluczowe komendy

cd C:\Users\Participant\DEV git clone https://github.com/TWOJ-LOGIN/jsystems-claude-code-2026-10.git cd jsystems-claude-code-2026-10

Tożsamość i autoryzacja GitHub - jednorazowo, na starcie

git config --global user.name "Imię Nazwisko" git config --global user.email "twoj@email.com" git config --global init.defaultBranch main
gh auth login # > GitHub.com | HTTPS | Authenticate Git: Yes # > Paste an authentication token -> github.com/settings/tokens # scopes: repo, read:org, workflow gh auth setup-git # tylko jeśli wybrałeś "No" wyżej
Alternatywa ręczna: klucz SSH (ssh-keygen + dodanie w GitHub Settings), wtedy remote jako git@github.com:...
git remote add upstream https://github.com/LucasMatuszewski/jsystems-claude-code-2026-10.git git checkout -b moja-praca
