Dostęp do maszyny Ubuntu

Adres maszyny (host i port) oraz login przekaże prowadzący na czacie Zoom. Każdy uczestnik ma własną maszynę; połącz się tylko z przydzieloną.

  • Windows: uruchom Podłączanie pulpitu zdalnego (mstsc) albo Windows App i wpisz host:port.
  • macOS: zainstaluj Windows App z App Store i dodaj komputer jako host:port.
  • Linux: użyj Remmina z protokołem RDP.

Jeśli sieć firmowa blokuje połączenie RDP na tym porcie, napisz do prowadzącego prywatną wiadomość na Zoom. Otrzymasz indywidualny dostęp przez portal w przeglądarce.

01. Narzędzia na VM

  • Claude Code CLI, Node.js, Git i VS Code są zainstalowane. Otwórz terminal i sprawdź wersje.
  • Sprawdź połączenie z Internetem i otwórz stronę materiałów. Zgłoś błąd dostępu prowadzącemu; nie udostępniaj haseł ani kluczy.
  • Logowanie do Claude wykonaj na swoim koncie. Nie zmieniaj konfiguracji cudzej sesji.
claude --version
node --version
git --version

Oczekujesz numerów wersji bez błędu "command not found". Zapisz je, jeśli różnią się od pokazu trenera.

02. Repozytorium i pierwsza sesja

Otwórz repozytorium uczestnika, pobierz je na VM i pracuj na własnej gałęzi. git status powinno pokazać stan tego katalogu. Następnie uruchom claude, sprawdź zaufanie do katalogu i wpisz /help. Nie wywołuj instalatora ponownie.

Repozytorium zawiera materiały i pusty szkielet. PRD, ADR oraz kod AI Chat powstaną na zajęciach.

03. Desktop i Linux

Głównym narzędziem jest CLI. Oficjalny Claude Desktop obsługuje Linux w wersji beta. Cowork na Linuxie wymaga KVM, QEMU i własnej maszyny wirtualnej, dlatego na maszynach kursowych (8 GB RAM) go nie uruchamiamy.

Punkt programu o Hyper-V dotyczy Windows. Nie konfigurujesz Hyper-V na Ubuntu. Ograniczenie zagnieżdżonej wirtualizacji zgłoś prowadzącemu; ćwiczenia programistyczne wykonasz w CLI.
